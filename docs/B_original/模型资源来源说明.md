# 模型资源及来源说明

## 1. UR5e 机械臂模型
- 来源：MuJoCo 官方模型库 universal_robots_ur5e
- 版本：标准 UR5e 六轴协作机械臂 MJCF 模型
- 包含内容：6节连杆、6个转动关节、基座、末端法兰与安装位点
- 参数依据：Universal Robots 官方 UR5e  DH 参数与几何尺寸

## 2. 场景自定义模型（自制）
| 物体 | 尺寸（长×宽×高） | 说明 |
| :--- | :--- | :--- |
| 工作台 | 1.0m × 0.9m × 0.7m | 长方体台面，机械臂安装于台面上 |
| 上料盘 | 0.2m × 0.2m × 0.01m | 蓝色，放置初始工件 |
| 下料盘 | 0.2m × 0.2m × 0.01m | 蓝色，放置搬运完成工件 |
| 工件方块 | 0.05m × 0.05m × 0.05m | 红色立方体，质量0.1kg |

## 3. 抓取接口
- 实现方式：weld 焊接约束
- 控制方式：通过 equality 约束的 active 属性切换抓取/释放
- 绑定对象：工件 workpiece 与末端连杆 wrist_3_link

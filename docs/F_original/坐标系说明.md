# UR5e 场景坐标系与关节核对说明

## 一、基坐标系（Base Frame）
1.  **定义**：UR5e 机械臂基座底面中心为原点，与世界坐标系原点重合。
2.  **轴向定义**：
    - X轴：水平向前，指向工作台作业区域
    - Y轴：水平向右
    - Z轴：垂直向上
3.  **位置**：世界坐标 (0, 0, 0)，与基座刚体 `base` 底面几何中心完全重合。
4.  **核对结论**：与 Universal Robots 官方 UR5e 基坐标系定义一致。

## 二、工具坐标系（TCP Frame）
1.  **定义**：以机械臂末端连杆 `wrist_3_link` 上的 `attachment_site` 站点为工具坐标系原点。
2.  **轴向定义**：
    - Z轴：沿法兰盘轴向向外，为工具工作方向
    - X、Y轴与末端法兰盘面平行，符合右手定则
3.  **相对偏移**：相对于 `wrist_3_link` 局部坐标系的偏移为 (0, 0.1, 0)。
4.  **核对结论**：作为后续抓取定位、轨迹规划的基准点，正向运动学计算结果与仿真器读取值一致。

## 三、轨迹数据文件格式

F 用 `load_e_trajectory()` 加载，支持三种格式，**任选一种**：

### 方式 A：`.npz`（推荐，最省事）

```python
import numpy as np
np.savez("e_traj.npz", time=time, q_traj=q_traj)
#   time   : shape (N,)   单位 s，单调递增，从 0 开始
#   q_traj : shape (N,6)  单位 rad
```

键名必须是 `time` 和 `q_traj`。

### 方式 B：`.csv`

首行表头，需含时间列与 6 个关节列：

```csv
t,q0,q1,q2,q3,q4,q5
0.0000,-1.106830,-1.483520,1.758360,-1.845640,-1.570800,0.463960
0.0100,-1.108291,-1.483519,1.758359,-1.845639,-1.570800,0.462751
...
```

时间列名可以是 `t` / `time`，关节列名可以是 `q0..q5` 或 `q_traj_0..q_traj_5`。

### 方式 C：`.npy`

直接是 `(N,6)` 数组，F 会按 dt=0.01 重建时间轴（**不推荐**，时间信息会丢失）。

## 四、⚠️ 采样周期：请用 dt = 0.002 s，或任意值都行但要知道这件事

F 的仿真是 **500 Hz（timestep = 0.002 s）**，执行方式是
「一个轨迹点 = 一次 `mj_step`」。

如果你用 **dt = 0.01 s** 输出（很常见），直接逐点执行会变成
**5 倍速播放**：声明 3.00 s 的轨迹实际只跑 0.602 s，
关节速度、加速度同步放大 5 倍，跟踪误差和 G 模块的误差分析全都会错。

**F 已经加了自动对齐**：检测到你的 dt ≠ 0.002 时，会在真实时间轴上
用三次样条重采样到 0.002 s 网格，保证"声明多久就跑多久"。
实测（dt=0.01、N=301、声明 3.00 s）：

| | 修复前 | 修复后 |
|---|---|---|
| 实际执行时长 | 0.602 s | **3.002 s** |
| 等效速度 | 5 倍速 | 1 倍速 |

所以你用 dt=0.01 也完全没问题，F 会自动处理并在日志里记一条
`时间尺度对齐` 事件。

**但如果你直接用 dt = 0.002 s 输出，就不触发重采样**，
F 逐点原样执行，时间尺度和导数都最精确。
两种方案（五次多项式、笛卡尔直线）的曲线也更贴近真实执行。

## 五、可选：一并给出 dq / ddq，跟踪精度更高

F 的控制律是 **计算力矩前馈 + PD 位置反馈**：

```
ctrl = q_cmd + [ M(q)·q̈_cmd + qfrc_bias + kv·q̇_cmd ] / kp
```

如果你的轨迹字典里带 `dq_traj[N,6]`（rad/s）和 `ddq_traj[N,6]`（rad/s²），
F 会自动用于前馈补偿，跟踪误差能从 11.85° 降到 0.147°（实测）。

不提供也能跑（`.npz` 加载时 F 会用 `np.gradient` 数值微分重建，
精度略低但够用）。

五次多项式如果按标准边界条件实现
（`q'(0)=q'(T)=0`, `q''(0)=q''(T)=0`），解析导数是：

```python
# q(τ) = a0 + a3·τ³ + a4·τ⁴ + a5·τ⁵,  τ = t/T
# a0 = q0, a3 = 10(q1−q0), a4 = −15(q1−q0), a5 = 6(q1−q0)
dq  = (3·a3·τ² + 4·a4·τ³ + 5·a5·τ⁴) / T
ddq = (6·a3·τ  + 12·a4·τ² + 20·a5·τ³) / T²
```

峰值速度 = `1.875·|q1−q0|/T`，可以用这个校核你的速度约束是否合理。

## 六、F 侧怎么接（你不用管，写给 A 和 F 自己看）

```bash
python src/control/controller.py --cycles 3 --traj-file path/to/e_traj.npz
```

F 会把你的轨迹用于 **transfer（平移）段**，其余段（接近、下降、抬升、
下放、退让、归位）仍由 F 的状态机控制——因为抓取/释放的时序与 weld
约束的激活必须和搬运流程严格配合。

如果你想让**整条搬运流程**都用你的轨迹，也可以：
把从抓取点到放置点的完整关节序列给我，我调整状态机的段划分。
提前说一声就行。

**加载失败的行为**：文件不存在、格式不符、`q_traj` 形状不是 `(N,6)`、
`time` 与 `q_traj` 长度不一致 —— F 会打印明确原因。
形状/长度错误抛 `ValueError`（不静默跑错轨迹），
文件不存在或扩展名不支持则回退到内置生成器并提示。

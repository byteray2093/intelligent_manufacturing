## 9. 遇到的问题及解决方法

### 9.1 Windows 字符编码问题

在环境配置过程中，曾遇到与 Windows 默认字符编码有关的读取问题。

使用以下命令设置 Python UTF-8 模式：

```cmd
set PYTHONUTF8=1
```

之后继续进行依赖安装和运行验证。

### 9.2 依赖下载问题

默认软件源下载依赖时曾出现连接问题。

改用清华大学 PyPI 镜像后，完成项目依赖安装。

### 9.3 MuJoCo 模型路径问题

项目最初位于含中文字符的文件夹路径下，运行集成版轨迹规划时出现 UR5e XML 模型加载失败。

检查发现模型 XML 文件本身存在，且使用相对路径进行模型加载测试可以成功。

随后将完整项目复制到不含中文字符的路径：

`C:\Users\lenovo\robot_test\intelligent_manufacturing-main`

重新创建虚拟环境并安装依赖后，轨迹规划、三次搬运和集成验收均成功运行。

因此，本次采用英文路径作为可靠的环境复现方案。上述现象不能单独证明所有中文路径都会导致 MuJoCo 加载失败。
